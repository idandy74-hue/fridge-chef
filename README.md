# fridge-chef
# 🍳 냉장고 파먹기 셰프 (Fridge Chef)
> **스마트 AI 식재료 구조대**  
> 냉장고 속 사진 한 장으로 시작하는 맞춤 요리 추천 2-Screen 웹 애플리케이션

---

## 📌 1. 프로젝트 개요
* **해결하고자 하는 문제**: 냉장고 속 자투리 식재료 방치로 인한 음식물 쓰레기 발생 및 매 끼니 메뉴 선택에 드는 결정 피로 해소
* **해결 방안**: 스마트폰 카메라로 냉장고 내부를 촬영하고 상시 보유 양념을 선택하면, 멀티모달 Vision AI가 식재료를 자동 판독하여 15분 내외 맞춤 레시피 2~3종을 즉시 생성
* **핵심 타겟**: 1인 가구, 자취생, 바쁜 직장인 및 가정

---

## 📱 2. 주요 기능 및 2-Screen 구성

### 📄 Screen 1. 재료 등록 및 촬영
* **스마트폰 카메라/앨범 연동**: 브라우저에서 바로 냉장고 내부를 촬영하거나 사진 업로드 (자동 이미지 압축 적용)
* **보유 양념 선택**: 간장, 고추장, 참기름 등 기본 양념 12종 중 보유 품목 다중 선택
* **요리 스타일 옵션**: 초간단(15분), 건강/다이어트식, 일품요리 선택
* **비상 데모 모드**: 실제 사진이 없는 환경에서도 원클릭으로 테스트 가능한 샘플 데이터 탑재

### 📄 Screen 2. 맞춤 레시피 리포트
* **식재료 감지 태그**: Vision AI가 사진에서 판독한 식재료 해시태그 목록 표시
* **추천 요리 카드 (2~3종)**:
  * 요리명, 난이도, 소요 시간
  * 냉장고 재료 및 사용 양념 구분 표기
  * 단계별 상세 조리법 (Step-by-step)
  * 셰프의 감칠맛 팁 및 남은 식재료 신선 보관법 안내

---

## 🛠️ 3. 기술 스택 (Tech Stack)
* **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+), FontAwesome
* **Backend**: Vercel Serverless Function (`/api/generate.js`)
* **AI Model**: Google Gemini API (`gemini-2.5-flash` Vision)
* **Deployment**: GitHub, Vercel

---
## 🔒 4. 보안 및 아키텍처
* **API 키 분리 보호**: 프론트엔드 코드에 API 키를 노출하지 않고, Vercel 서버리스 함수(`api/generate.js`) 내의 환경변수(`GEMINI_API_KEY`)를 통해 통신하도록 설계되었습니다.
